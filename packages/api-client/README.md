# @itrms/api-client

The API's contract and a typed client on it.

| File | What |
|---|---|
| `openapi.json` | the contract, generated from the API's Zod schemas (`pnpm openapi`); committed |
| `src/schema.d.ts` | its TypeScript types (`paths`, `components`), generated by `generate.mjs`; committed |
| `src/index.ts` | `createApiClient({ baseUrl, fetch })` (openapi-fetch) and the `Problem` type |

After changing the API, run `pnpm openapi` (it rebuilds the API, writes `openapi.json` and regenerates the types). Two
drift tests fail CI otherwise: `apps/api/src/openapi.spec.ts` (the contract) and `src/schema.spec.ts` (the types).

Rules: [code-structure.md](../../docs/platform/code-structure.md) §3 and §7.
